# 🦾 BionicPRO - Система аналитики бионических протезов

## 🎯 Бизнес-контекст

**BionicPRO** производит и обслуживает бионические протезы нового поколения. Система аналитики собирает данные:

- **Из CRM (Битрикс24)**: заказы, клиенты, статусы производства
- **С протезов**: телеметрия использования, состояние устройств, ошибки
- **Для отчетов**: продажи, техническое состояние, эффективность

### 👥 Пользователи системы

| Роль | Потребности | Доступ к данным |
|------|-------------|-----------------|
| **Руководство** | Стратегические отчеты, KPI | Агрегированные данные, дашборды |
| **Отдел продаж** | Мониторинг заказов, конверсия | CRM данные, воронка продаж |
| **Техподдержка** | Состояние устройств, превентивный ремонт | Телеметрия, ошибки, health score |
| **Производство** | Статус изготовления, сроки | Производственные заказы |
| **Клиенты** | Отчеты по их протезам | Только свои данные (изоляция) |

### 📊 Структура данных в ClickHouse

bionicpro_analytics/
├── crm_orders # Заказы из Битрикс24
│ └── Обновляется: ежедневно в 03:00
├── prosthesis_telemetry # Телеметрия с протезов
│ └── Обновляется: ежедневно в 03:00
├── sales_mart # Витрина продаж
│ └── Обновляется: каждый час
├── prosthesis_health_mart # Витрина состояния протезов
│ └── Обновляется: каждый час
└── daily_sales_summary # MV для быстрых отчетов
└── Автообновление при вставке


### ⚠️ Особенности медицинских данных

1. **Конфиденциальность**: Анонимизация персональных данных клиентов
2. **Изоляция**: Каждый пользователь видит только свои данные
3. **Аудит**: Логирование всех обращений к медицинским данным
4. **Согласие**: Учет согласий на обработку данных

### 🚀 Запуск системы BionicPRO

```bash
# 1. Клонирование и настройка
git clone <репозиторий>
cd bionicpro-analytics
cp .env.example .env  # Настройте параметры BionicPRO

# 2. Запуск
docker-compose up -d --build

# 3. Инициализация БД
docker-compose exec clickhouse clickhouse-client --queries-file /docker-entrypoint-initdb.d/init-bionicpro-clickhouse.sql

# 4. Проверка DAG
docker-compose exec airflow-scheduler airflow dags list | grep bionicpro
